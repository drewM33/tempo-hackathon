## Phase 1: Build and Boot

- **Clean install** — `pnpm install` completes with zero dependency errors
- **Dev server starts** — `pnpm dev` runs without build-time TypeScript or module resolution errors
- **Page loads** — navigating to the dashboard route renders without a white screen or console errors
- **No hydration crashes** — the only hydration warnings in console are from browser extensions (Grammarly, etc.), not from your code


## Phase 2: Visual Verification

- **Dark theme applied** — background is near-black (`#0a0a0f`), all text is legible, no white/unstyled flashes
- **5 KPI cards render** — Total Requests, Active Agents, Blocked Attempts, Revenue Protected, CER -- all showing numbers, not `NaN` or `undefined`
- **Pricing chart renders** — 9 horizontal bars from AAA (green) to C (red), with "BLOCKED" label on C tier
- **9 agent wallet cards render** — each with address, tier badge, sparkline, price, CER row, grade history dots, and risk strip
- **API Endpoints tab works** — clicking the toggle switches to endpoint cards without unmounting errors


## Phase 3: Live Data Verification

- **KPI numbers are ticking** — watch any KPI card for 5 seconds, value should change
- **Sparklines are animating** — the line charts on wallet and endpoint cards should shift left as new points append
- **CER values fluctuate** — the per-agent CER and trend percentage should update every few seconds
- **Event log scrolls** — new colored rows should appear every ~4 seconds at the top of the log


## Phase 4: Interactivity

- **Call button works** — click "Call" on a non-blocked agent, see the spinner, progress bar, then success (time) or error (retry) state
- **Blocked agents have no Call button** — C-tier and BLOCKED agents should show no call option
- **Tooltips appear on hover** — hover over any KPI card, tier badge, CER value, or sparkline and see an explanatory tooltip
- **Tab toggle persists** — switching between "Active Agent Wallets" and "API Endpoints" preserves data state


## Phase 5: Chat Command Center

- **Chat opens** — clicking the green bubble expands the chat panel
- **Suggested prompts work** — clicking a chip like "What is CER?" returns a contextual response
- **Query commands** — type `list agents` and confirm it returns all 9 agents with their tiers and CER values
- **Downgrade command** — type `downgrade 0x[partial address] high infra costs`, confirm the chat shows an ACTION response, then check the wallet card -- its tier badge should have stepped down one level
- **Upgrade command** — same test in reverse with `upgrade`
- **Tell directive** — type `tell 0x[address] reduce batch sizes`, confirm a directive log entry appears
- **Show low CER** — type `show low cer`, confirm it lists only agents with CER below 0.6x


## Phase 6: Edge Cases

- **Rapid tab switching** — toggle between Wallets and Endpoints 10 times quickly, no crashes or memory leaks
- **Multiple calls simultaneously** — click Call on 3+ agents in quick succession, each should independently resolve
- **Chat while data ticks** — issue a downgrade command while live data is ticking, confirm no race condition (the downgraded tier should persist, not get overwritten by the next tick)
- **Resize to mobile** — cards should reflow from 3 columns to 2 to 1, chat widget stays accessible
